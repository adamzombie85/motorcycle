# 遊戲化與通用設計規格

> 2026-10-22 版，Claude 撰寫，Jim 決定全部採用（功能 1～7）。
> 原則：**獎勵努力，不懲罰缺席**；不計時、不排名；所有動畫、音效都可以關掉。

## 1. 每日 3 分鐘挑戰
- 每天一組 **5 題**，日期以裝置的當地時間計算，凌晨 0 點換新的一組
- 出題順序（不足就往下一項補）：
  1. 「今天到期」的錯題（見第 5 節），最多 2 題
  2. 「畢業檢查」到期的題目（見第 5 節），最多 1 題
  3. 新題目：從**累計答對率最低的小類**裡，挑還沒作答過的題目；全部做過就從答錯過的題目挑
- 當天的 5 題固定不變（重新整理也一樣），做完顯示「今日挑戰完成 ✓」
- 不計時；中途離開，下次回來從還沒做的題目接著做

## 2. 連續練習天數＋休息卡
- **打卡條件**：當天完成每日挑戰，**或**當天累計作答滿 5 題
- **休息卡**：每週（週一到週日）自動有 1 張。漏掉 1 天時自動使用，連續天數不中斷；同一週漏掉第 2 天，連續天數才歸 0
- 歸 0 時的文字要溫和，例如「新的開始！今天是第 1 天」，**不顯示「你中斷了」**
- 首頁顯示：連續天數、本週 7 天的打卡格子（打卡／休息卡／未來）

## 3. 考照之路地圖
- 92 關排成一條路線，依 11 個小類分成 5 個「路段」，每段用一張 Gemini 場景圖當背景：
  | 路段 | 場景圖 | 小類 |
  |---|---|---|
  | 1 出發前準備 | `map-1-garage` 車庫與出發 | 行車檢查、貨物裝載 |
  | 2 市區路口 | `map-2-city` 市區路口 | 路口安全、轉彎、注意大型車 |
  | 3 一般道路 | `map-3-road` 一般道路 | 行駛中應注意事項、正確使用燈光 |
  | 4 特殊路況 | `map-4-special` 平交道與雨天 | 平交道…駕駛道德、禁止不當行為 |
  | 5 終點考場 | `map-5-goal` 監理站考場 | 事故預防及處理、情境題 |
- 每一站顯示狀態：未練習／已練習（最高分）／過關 ✓。**不鎖關**，任何一站都可以點
- 主角機車停在「最近練習的那一站」
- 地圖是另一種瀏覽方式，原本的清單保留（有些人用清單比較方便）

## 4. 徽章（12 個）
| 代號 | 名稱 | 取得條件 |
|---|---|---|
| first-ride | 出發了！ | 完成第 1 關 |
| perfect | 全對達人 | 任一關全部答對 |
| streak-3 | 三天不間斷 | 連續練習 3 天 |
| streak-7 | 一週騎士 | 連續練習 7 天 |
| streak-30 | 月度車神 | 連續練習 30 天 |
| reverse-20 | 反向題剋星 | 反向題累計答對 20 題 |
| clean-up | 錯題清道夫 | 錯題庫從「有題目」清到 0 題 |
| sign-30 | 看圖高手 | 有圖題累計答對 30 題 |
| region | 路段制霸 | 任一路段的關卡全部過關 |
| q-100 | 百題里程 | 累計作答 100 題 |
| q-500 | 五百題里程 | 累計作答 500 題 |
| daily-7 | 挑戰常客 | 完成每日挑戰 7 次（不用連續） |
- 取得時跳出慶祝畫面（可關動畫）；徽章頁顯示已取得和未取得，未取得的顯示灰色剪影和條件
- 徽章只會增加，不會被收回

## 5. 錯題定期回來（間隔複習）
沿用「連續答對 2 次移出」的規則，再加上時間間隔：
- 答錯 → 進錯題庫，**隔天**到期
- 錯題答對第 1 次 → **3 天後**到期
- 錯題答對第 2 次 → 移出錯題庫，排一次「畢業檢查」在 **7 天後**
- 畢業檢查答對 → 完全畢業；答錯 → 重新進錯題庫
- 錯題庫頁照常可以隨時練全部錯題（到期只影響「每日挑戰」怎麼挑題）

## 6. 動畫與音效
- 答對：短促的提示音＋選項輕微彈跳；過關：彩帶；取得徽章：徽章放大出現
- 音效用瀏覽器 Web Audio 即時產生，不放音檔（不用處理授權）
- 閱讀設定新增兩個開關：**音效**（預設開）、**動畫**（預設開；裝置設定了「減少動態效果」時預設關）

## 7. 自訂角色
- 6 位騎士可選（Gemini 生圖，同一畫風、不同安全帽與機車顏色、不同髮型）
- 4 位一開始就能選；2 位分別在取得「一週騎士」「月度車神」徽章時解鎖
- 選好的角色出現在：首頁、地圖上的機車、學習成果報告
- **情境插圖分男生版、女生版**（2026-10-23 Jim 要求）：選 rider-2、rider-4（女騎士）時，過關、錯題清空、每日完成等情境圖顯示女生版（檔名加 `-f`，例如 `celebrate-level-f.png`）；其他角色顯示原版
- 登入頁、成績單主圖用男女主角同框的版本（`login-welcome-duo.png`、`report-header-duo.png`），因為還不知道是誰

## 8. 確認作答（閱讀設定裡的選項）
- 預設關。開啟時：點選項只是「選取」，要再按「確認作答」才送出，避免誤觸

## 不做的事
- 排行榜、和別人比較
- 倒數計時
- 連續天數中斷時的負面訊息
- 用 AI 自己產生法規解析（要等階段 3 概念卡，Jim 審核）

## 附：階段 4 危險秒數標註（省額度做法，2026-10-23 Jim 要求）

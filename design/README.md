## 一、設計理念與使用者核心原則

本專案服務對象為**特教資源班高中生**，在手機與平板上準備機車駕照新制筆試（全選擇題 50 題，含 15 題危險感知）。在視覺與互動設計上，落實四大核心原則：

1. **清楚、友善、不幼稚、零考試壓力：**
   - 介面避免傳統駕訓班死板冷硬的「試卷感」，也避免過度低齡的幼兒化設計，尊重高中生的年齡心智。
   - 採用柔和天青藍底色與大圓角卡片，版面呼吸感充足，降低文字密集帶來的焦慮。
2. **小關卡、高頻即時回饋：**
   - 以「一回合 10 題」微關卡作為主要學習節奏，答完一題或一關即時給予清晰的正向反饋。
3. **無障礙特教閱讀輔助 (WCAG 2.1 AA)：**
   - **字級嚴格 >= 18px：** 全系統次要輔助文字亦不低於 18px，正文採用 20px，題目採 24px，保障閱讀與識字友善。
   - **觸控目標 >= 44px：** 所有按鈕與選項卡最小可點擊範圍設定為 48px ~ 56px，大幅降低手部微動作或行動裝置誤觸率。
   - **雙重感官識別（不只靠顏色傳遞資訊）：** 答對或答錯除了色框變化外，必備「文字標籤」（如：`✔ 正確答案`、`✖ 你的選擇`）與專屬幾何圖示，色盲或弱視學生也能 100% 準確理解。
4. **反向題與易錯題主動防護：**
   - 新制題庫中有約 54 題「何者不正確／何者錯誤」的反向題，特教學生極易看反。
   - 設計專屬的醒目黃橘色警告橫幅 `alert-reverse`，並在題目文字中自動以螢光筆效果 `mark.highlight-reverse` 強調「不正確」，破除閱讀盲點。

## 四、元件規格與使用指引 (Components Guide)

### 1. 按鈕元件 (`.btn`)
- **使用時機：**
  - `.btn-primary`：主推動行動（如「開始練習」、「下一題」、「立即加強弱點」）。
  - `.btn-secondary`：次要操作（如「上一題」、「看詳細解析」、「記住觀念看下一題」）。
  - `.btn-accent`：特殊成就或解鎖（如「查看學習徽章」、「弱點特訓」）。
  - `.btn-outline`、`.btn-ghost`：輔助操作（如「暫停離開」、「回首頁」）。
  - `.btn-lg`：主要作答前進按鈕，高度達 56px，大面積容易點擊。
  - `.btn-icon`：語音朗讀 🔊、注音 ㄅ、字級 🔍 等輔助功能，固定 48x48px 觸控盒。

### 2. 選項卡元件 (`.option-card`)
- **五種關鍵狀態：**
  1. **Default（預設狀態）：** 純白底、灰邊框，序號圓角徽章（1, 2, 3）。
  2. **Selected（選取狀態）：** 湖水藍邊框（3px）加淺藍底，伴隨藍色焦點環。
  3. **Correct（答對狀態）：** 翡翠綠厚邊框（3px）、淡綠背景、序號變為綠底 ✔、右側顯眼標籤 `✔ 正確答案`。
  4. **Wrong（答錯狀態）：** 珊瑚紅厚邊框（3px）、淡粉背景、序號變為紅底 ✖、右側顯眼標籤 `✖ 你的選擇`。
  5. **Dimmed（未選中淡化）：** 檢討時半透明淡化（透明度 0.55），突顯正確與錯誤之對比。

### 3. 進度指示元件
- **10 題微關卡圓點 (`.progress-dots`)：**
  - 每回合固定 10 題。
  - `.dot-item.is-done`（已答對：綠色圓點）。
  - `.dot-item.is-wrong`（答錯：紅色圓點，提示已排入錯題庫）。
  - `.dot-item.is-current`（當前題：放大湖水藍圓點 + 呼吸外環）。
- **及格門檻標記連續進度條 (`.pass-mark-indicator`)：**
  - 在連續進度條上精準標記 **85 分及格標準線**，讓學生一眼看出自身成績與及格線的距離。

### 4. 回饋與輔助卡片
- **答對回饋 (`.feedback-card.is-success`)：**
  - 讚美學生，消除焦慮。
  - 核心口訣框 (`.concept-memo`)：將法規條文轉化為 1~2 句易記口訣（例如：「載物口訣：寬 10 公分、長 50 公分、高不過肩！」）。
- **答錯回饋 (`.feedback-card.is-danger`)：**
  - 語氣溫和鼓勵：「這題選錯囉，沒關係！💪」。
  - 清楚說明為何選這個選項是錯的、法規正確規定是什麼。
  - 錯題機制標示 (`.mistake-retest-notice`)：「已加入錯題庫，連續答對 2 次算過關」。
- **反向題警告橫幅 (`.alert-reverse`)：**
  - 亮黃背景搭配紅字與 ⚠️ 圖示，提醒學生：「注意！這題問【何者不正確】，請找出錯誤敘述」。

### 5. 成績與圖表區塊 (符合規格書要求)
- **圓形計分儀表 (`.score-badge-circle`)：** 居中巨大分數（例如 90 分），搭配合格徽章（`🎉 本關已合格（及格標準 85 分）`）。
- **弱點改善建議 Banner (`.recommend-banner`)：** 自動計算得分最低的小類別，並提供「立即強化此弱點 ➔」大按鈕，直接帶入練習。
- **三大圖表容器：**
  - **雷達圖：** 呈現正確觀念、主動停讓、安全駕駛、危險感知四大面向能力。
  - **由低到高長條圖：** 將各小類掌握度由低到高排序，弱點一眼即知。
  - **歷次練習趨勢折線圖：** 呈現學習進步曲線，激勵信心。
  - 支援一鍵匯出供特教老師 IEP 學習檔案使用。

## 六、給下一棒 Claude Code 的接棒指引

1. **樣式引用：** 在 `site/` 實作時，請直接引入 `design/tokens.css` 與 `design/components.css`，所有按鈕、卡片、文字色彩請嚴格使用 `var(--...)`。
2. **題目反向題偵測：** 題目若帶有標籤 `反向題` 或題目文字含「不正確」、「何者錯誤」，請套用：
   - `<div class="alert-reverse">...</div>`
   - 題目文字關鍵字包裹 `<mark class="highlight-reverse">不正確</mark>`
3. **圖片來源：** 題庫中的交通標誌與情境圖，請引用 `media/images/[題目編號].png` 或 `.jpg`，套用 `.question-image-frame` 樣式。
4. **圖表呈現：** 結算頁中的雷達圖與長條圖，工程端已約定使用 **Chart.js**，可直接掛載於 `.chart-wrapper` 的 `<canvas>` 中，Chart.js 配色請使用：
   - 湖水藍 Primary: `rgba(44, 157, 176, 0.7)` / `rgba(44, 157, 176, 0.2)`
   - 翡翠綠 Success: `#059669`
   - 珊瑚紅 Danger: `#E11D48`
   - 琥珀黃 Accent: `#F59E0B`

## 一、設計理念與通用設計核心原則

本專案服務對象為**全校高中生**，採**通用設計（Universal Design）**理念，讓每位學生都使用同一套友善、好讀、低挫折的網站，在手機與平板上準備機車駕照新制筆試（一次 50 題，含 15 題危險感知）。朗讀、注音、字級等輔助功能為「每個人都能用的閱讀設定」，尊重學生自主需求，消除標籤化。

在視覺與互動設計上，嚴格落實四大核心原則：

1. **清楚、友善、不幼稚、零考試壓力：**
   - 介面避免傳統駕訓班死板冷硬的「試卷感」，也避免過度低齡的幼兒化設計，符合高中生的年齡心智與自我認同。
   - 採用柔和天青藍底色與大圓角卡片，版面呼吸感充足，降低文字密集帶來的焦慮與排斥。
2. **小關卡、高頻即時回饋：**
   - 官方 1,052 題庫按小類切分為「一回合 10 題」微關卡（共 92 關），學生自由選題不鎖關。
   - 答完一題即時給予客觀清楚的正向回饋（僅顯示對錯與官方答案，不出現未經審核的口訣或解析）。
3. **無障礙通用閱讀與操作輔助 (WCAG 2.1 AA)：**
   - **字級嚴格 >= 18px：** 全系統次要輔助文字亦不低於 18px，正文採用 20px，題目採 24px，全體學生皆能輕鬆舒適閱讀。
   - **觸控目標 >= 44px：** 所有按鈕與選項卡最小可點擊範圍設定為 48px ~ 56px，大幅降低手部微動作或行動觸控誤觸率。
   - **雙重感官識別（不只靠顏色傳遞資訊）：** 答對或答錯除了色框變化外，必備「文字標籤」（如：`✔ 正確答案`、`✖ 你的選擇`）與專屬幾何圖示，開關元件亦必備「開／關」文字標記，確保色彩辨識不敏感者也能 100% 準確理解。
   - **頂部單一「⚙️ 閱讀設定」按鈕：** 取代舊版三個分散圖示，整合文字＋圖示的大尺寸按鈕（點擊開啟閱讀設定抽屜面板），包含字級（標準／大／特大）、注音（開／關）、朗讀（自動開關與語速）、反向題提醒（開／關）與恢復預設。
   - **單題手動朗讀按鈕保留：** 答題畫面題目卡旁一律保留「🔊 朗讀本題」大按鈕，無論自動朗讀是否開啟，皆可手動隨時點按。
4. **反向題與易錯題主動防護：**
   - 新制題庫中有約 54 題「何者不正確／何者錯誤」的反向題，極易因看太快而選反。
   - 設計專屬的醒目黃橘色警告橫幅 `alert-reverse`，並在題目文字中自動以螢光筆效果 `mark.highlight-reverse` 強調「不正確」，破除閱讀盲點。

## 三、交付檔案結構與職責

Antigravity 專注於視覺定調與畫面樣板，交付於 `design/` 目錄中，完全不使用任何第三方外部 CSS 框架（純原生 Vanilla CSS），無建置依賴：

```text
design/
├── tokens.css          # 核心樣式變數庫：色彩、字級 (>=18px)、間距、圓角、陰影、通用無障礙規範、注音字型與字級縮放階層
├── components.css      # 可複用元件庫：按鈕、Google 登入、選項卡、進度條、回饋卡、圖表容器、關卡卡片、成果報告單、閱讀設定抽屜、開關與三段選擇
├── components.html     # 元件庫展示與規範頁 (Living Styleguide，含通用設計、無題幹圖片題與閱讀設定專用元件展示)
├── screen-home.html    # 關鍵畫面樣板 1：首頁樣板 (微關卡、學習進度、特訓專區、全真 1,052 題、92 關、單一閱讀設定按鈕)
├── screen-quiz.html    # 關鍵畫面樣板 2：答題畫面樣板 (10題進度、反向題提醒、無題幹圖片題、即時回饋、單題手動朗讀按鈕)
├── screen-result.html  # 關鍵畫面樣板 3：成績結算樣板 (分數徽章、及格線、四大類雷達圖、弱點建議、匯出圖表、閱讀設定按鈕)
├── screen-login.html   # 關鍵畫面樣板 4：Google 帳號登入與首次登入選填班級座號表單 (雙狀態預覽切換)
├── screen-levels.html  # 關鍵畫面樣板 5：小類關卡清單 (25 關卡多關卡排版、三種狀態標章、自由選關不鎖定)
├── screen-mistakes.html# 關鍵畫面樣板 6：錯題特訓庫 (連續答對 2 次移出追蹤、有錯題與無錯題鼓勵雙畫面)

├── screen-settings.html# 關鍵畫面樣板 8：閱讀設定抽屜面板 (手機底部滑出／桌機右側滑出、字級即時預覽、芫荽注音、自動朗讀與語速、反向題提醒)
└── README.md           # 本文件：設計理念、元件規範、注音字型授權與各階段交接紀錄
```

## 四、元件規格與使用指引 (Components Guide)

### 1. 按鈕元件 (`.btn`)
- **使用時機：**
  - `.btn-primary`：主推動行動（如「開始練習」、「下一題」、「立即加強弱點」）。
  - `.btn-secondary`：次要操作（如「上一題」、「記住觀念看下一題」）。
  - `.btn-accent`：特殊成就或解鎖（如「查看學習徽章」、「弱點特訓」）。
  - `.btn-outline`、`.btn-ghost`：輔助操作（如「暫停離開」、「回首頁」）。
  - `.btn-lg`：主要作答前進按鈕，高度達 56px，大面積容易點擊。
  - `.btn-icon`：語音朗讀 🔊、注音 ㄅ、字級 🔍 等輔助功能，固定 48x48px 觸控盒。

### 2. Google 帳號登入按鈕與選填表單 (`.btn-google`, `.login-card`, `.login-input`)
- **使用時機：** 學生進入首頁前的帳號登入與首次身分確認畫面（`screen-login.html`）。
- **通用設計規範：**
  - **Google 帳號登入：** 採用 `.btn-google` 大觸控按鈕（高度 56px，字級 20px），內嵌官方四色「G」標誌 SVG，清楚標註「使用 Google 帳號登入」。不限學校網域，任何 Google 帳號皆可使用。
  - **首次登入選填表單：** 登入後引導學生設定班級與座號。此步驟為**明確標示之【選填】**，提供醒目、大尺寸的「先跳過，直接進入練習 ➔」按鈕與「儲存並開始練習 ➔」按鈕，給予學生完全自由與最低心理門檻。
  - **學生身分呈現：** 有填寫時全站身分徽章呈現「301 班 12 號」格式；若未填寫則親切顯示「同學」。

### 3. 選項卡元件 (`.option-card`)
- **五種關鍵狀態：**
  1. **Default（預設狀態）：** 純白底、灰邊框，序號圓角徽章（1, 2, 3）。
  2. **Selected（選取狀態）：** 湖水藍邊框（3px）加淺藍底，伴隨藍色焦點環。
  3. **Correct（答對狀態）：** 翡翠綠厚邊框（3px）、淡綠背景、序號變為綠底 ✔、右側顯眼標籤 `✔ 正確答案`。
  4. **Wrong（答錯狀態）：** 珊瑚紅厚邊框（3px）、淡粉背景、序號變為紅底 ✖、右側顯眼標籤 `✖ 你的選擇`。
  5. **Dimmed（未選中淡化）：** 檢討時半透明淡化（透明度 0.55），突顯正確與錯誤之對比。

### 4. 進度指示元件
- **10 題微關卡圓點 (`.progress-dots`)：**
  - 每回合固定 10 題。
  - `.dot-item.is-done`（已答對：綠色圓點）。
  - `.dot-item.is-wrong`（答錯：紅色圓點，提示已排入錯題庫）。
  - `.dot-item.is-current`（當前題：放大湖水藍圓點 + 呼吸外環）。
- **及格門檻標記連續進度條 (`.pass-mark-indicator`)：**
  - 在連續進度條上精準標記 **85 分及格標準線**，讓學生一眼看出自身成績與及格線的距離。

### 5. 回饋與輔助卡片
- **答對回饋 (`.feedback-card.is-success`)：**
  - 給予學生溫暖肯定，消除焦慮。
- **答錯回饋 (`.feedback-card.is-danger`)：**
  - 語氣溫和鼓勵：「這題選錯囉，沒關係！💪」。
  - 清楚說明為何選這個選項是錯的、官方正確答案是什麼。
  - 錯題機制標示 (`.mistake-retest-notice`)：「已加入錯題庫，連續答對 2 次算過關」。
- **反向題警告橫幅 (`.alert-reverse`)：**
  - 亮黃背景搭配紅字與 ⚠️ 圖示，提醒學生：「注意！這題問【何者不正確】，請找出錯誤敘述」。

### 6. 無題幹官方圖片題型提示句 (`.question-stem-prompt`)
- **使用時機：** 官方題庫中有大量標誌與情境題目（如 M0067 等）題幹文字為空字串 `question: ""`。為避免學生閱讀誤解或以為載入失敗，系統統一於題目區塊呈現湖水藍引導提示句：`👉 請看圖，選出正確的答案。`
- **結構規範：** 支援螢幕閱讀器與語音朗讀，字級為 24px (`var(--font-size-lg)`)，左側帶 4px 品牌主色強調線。

### 7. 小類關卡清單元件 (`.level-item-grid`, `.level-item-card`, `.level-item-badge`)
- **使用時機：** 某一小類的大量關卡瀏覽與自由挑題（`screen-levels.html`）。
- **設計考量：**
  - **全關卡不鎖定：** 學生可自由挑選關卡練習，全部關卡卡片均可點擊進入作答（`screen-quiz.html`）。
  - **三種直覺狀態標章（文字 + 符號雙重感官）：**
    - `✔ 已過關 · 90 分`（綠底白字/深綠字，含 ✔ 標誌）
    - `⚡ 練習中 · 最高 70 分`（琥珀黃底，含 ⚡ 標誌與尚差幾分及格提示）
    - `⚪ 未開始`（淺灰底，含 ⚪ 標誌，清楚標記「自由挑戰 · 不鎖關」）
  - **RWD 格線排版：** 手機端（375px）單欄垂直大卡片，平板與桌面（768px~1024px）自動轉為 2~3 欄響應式網格。

### 8. 錯題特訓庫與連續答對 2 次移出追蹤 (`.mistake-streak-box`, `.streak-dot`, `.empty-state-card`)
- **使用時機：** 錯題複習畫面（`screen-mistakes.html`）。
- **機制亮點：**
  - **雙重圓點進度 (`.streak-dot`)：** 具體呈現每題「連續答對進度 0/2 次」或「1/2 次」，當達到第 2 次答對時自動光榮移出，給予學生即時肯定。
  - **官方真實對錯回饋：** 依據階段 1 規範，僅標記使用者先前答錯之選項與官方正確選項，**不顯示任何 AI 自編未經審核之口訣或解析**，確保法規知識百分之百精準。
  - **全數通關鼓勵畫面 (`.empty-state-card`)：** 當錯題庫清空時，展示溫暖慶賀勳章（🏆✨），引導學生返回關卡清單繼續推進。

### 9. 我的學習成果報告直式成績單 (`.report-sheet`, `.report-stat-grid`, `.report-section-card`)
- **使用時機：** 個人學習歷程與成果總結畫面（`screen-report.html`）。
- **設計特點：**
  - **直式圖片長圖規格：** 針對存成寬約 1080px 的長圖設計，非常適合作為學生存檔、透過 LINE 傳送給指導老師或家長分享的直式成績單。
  - **不顯示 email：** 嚴格維護學生個資隱私，僅顯示班級座號（如「301 班 12 號」，若未填則顯示「同學」）、統計日期與練習總時數。
  - **四大核心學習區塊：**
    1. **四大摘要指標：** 累計練習題數、過關關卡數（目前共 92 關，85 分及格判定）、累計平均答對率、待複習錯題數。
    2. **四大面向能力雷達圖：** 正確觀念與態度、主動停讓文化、安全駕駛能力、危險感知（影片題）。
    3. **各小類掌握度長條圖（由低到高排列）：** 優先顯示答對率較低的小類（如平交道、強制險等），清晰標示答錯題數與強化建議。
    4. **最近 10 次練習成績趨勢（含 85 分及格標準紅線）：** 直觀展現學習進步曲線與過關穩定度。
    5. **錯題診斷與指導叮嚀：** 給予學生鼓勵與具體的複習方向。

### 10. 閱讀設定觸發按鈕 (`.btn-settings`)
- **使用時機：** 頂部通用導覽列（Site Header）右上角，全站統一入口。
- **無障礙通用規範：**
  - **圖示＋文字雙重標記：** 規格嚴格要求「不能只有圖示」，採用 `<span class="btn-settings-icon">⚙️</span> <span class="btn-settings-text">閱讀設定</span>`。
  - **觸控目標 >= 44px：** 最小高度設定為 `var(--touch-target-min)` (48px)，左右內距 18px，大字級 18px，手指極易點按。
  - **親和膠囊造型：** 純白底搭配淺青藍外框，懸浮與焦點時有清晰焦點環 (`--focus-ring`)。

### 11. 閱讀設定抽屜面板與響應式 RWD 佈局 (`.drawer-panel`, `.drawer-backdrop`)
- **使用時機：** 學生點擊「⚙️ 閱讀設定」後滑出之輔助調整面板（`screen-settings.html`）。
- **RWD 響應式行為：**
  - **手機端 (< 768px)：** 自底部向上滑出（Bottom Sheet），具有頂部灰色拖曳把手（`.drawer-handle-bar`）、大圓角（`28px 28px 0 0`）、最大高度 90vh，可上下平順滾動。
  - **平板與電腦端 (>= 768px)：** 自右側向左滑出抽屜（Side Sheet Drawer），寬度 480px，高度 100vh，左側帶 3px 品牌主色強調邊框。
  - **半透明遮罩 (`.drawer-backdrop`)：** 背景具備毛玻璃效果 (`backdrop-filter: blur(4px)`)，點擊灰色遮罩或右上角「✕」按鈕均可關閉收合。

### 12. 無障礙開關元件 (`.toggle-wrapper`, `.toggle-track`, `.toggle-thumb`)
- **通用設計核心要求：開關狀態絕不能只靠顏色傳遞！**
  - **軌道內刻印文字：** 軌道內左側內建「開」、右側內建「關」文字，字級 >= 18px。開啟時滑塊右移露出「開」字，關閉時露出「關」字。
  - **狀態文字徽章 (`.toggle-status-badge`)：** 開關旁隨附「已開啟 ✔」或「已關閉 ✕」標籤，達成多重感官識別。
  - **觸控友善：** 軌道高度達 44px，寬度 84px，搭配直徑 34px 大滑塊，支援鍵盤 Space/Enter 切換與 `:focus-visible` 焦點環。

### 13. 三段選擇元件 (`.segmented-group`, `.segmented-btn`)
- **使用時機：** 字級大小（標準／大／特大）、朗讀語速（慢速／正常／快速）。
- **設計規範：**
  - 每個分段按鈕高度達 52px，內部包含大字主標（20px）與次要說明（18px）。
  - 選中狀態具有純白底色、品牌主色邊框（2px）、粗體字與微立體陰影，未選中項對比度維持在 5:1 以上。

### 14. 開源注音字型規格（芫荽注音）
- **字型名稱：** 芫荽注音（英文名稱：**Iansui Bopomofo** / 芫荽注音體）
- **字型來源：** 由台灣開源字型開發者 **ButTaiwan（But Ko）** 基於日本 Fontworks 之開源字型「Klee One」（克里體）進行台灣教育部常用字元補完與注音符號排版封裝之開源專案。
  - 專案首頁 / GitHub：`https://github.com/ButTaiwan/iansui`
  - 注音字型專案：`https://github.com/ButTaiwan/bpmf-font`
- **授權條款：** **SIL Open Font License 1.1 (SIL OFL-1.1)**
  - **100% 開放授權：** 免費商用、免授權費、自由散布、自由改作，絕無版權侵權風險。
- **網頁排版整合：**
  - CSS 變數：`--font-family-zhuyin: "IansuiBpmf", "Iansui", "芫荽注音", "BpmfIansui", var(--font-family-sans);`
  - 當開啟注音輔助時，在 body 加上 `.mode-zhuyin`。
  - 同步支援標準 HTML5 `<ruby>` 與 `<rt>` 標籤排版，確保任何裝置與瀏覽器皆能清晰閱讀。

### 15. 字級縮放階層與即時預覽卡 (`.reading-preview-box`)
- **三段字級縮放階層：**
  - **標準 (Normal)：** 正文 20px (`1.25rem`)，題幹 24px (`1.5rem`)，輔助 18px (`1.125rem`)。
  - **大 (Large，`html.font-size-large`)：** 正文 23px (`1.4375rem`)，題幹 28px (`1.75rem`)，輔助 20px (`1.25rem`)。
  - **特大 (Extra Large，`html.font-size-xlarge`)：** 正文 26px (`1.625rem`)，題幹 32px (`2rem`)，輔助 22px (`1.375rem`)。
- **即時預覽驗證：**
  - 面板內設有「字級即時預覽框」，選取字級時動態同步放大，讓學生在儲存前先確認閱讀體感。
  - 底層題目卡與選項採用彈性相對單位，在「特大 (32px)」字級下，題目與選項文字均自動向下延展，**絕不截斷、破版或覆蓋按鈕**。

## 六、給下一棒 Claude Code 的接棒指引

1. **樣式引用：** 在 `site/` 實作時，請直接引入 `design/tokens.css` 與 `design/components.css`，所有按鈕、卡片、文字色彩請嚴格使用 `var(--...)`。
2. **閱讀設定狀態持久化 (localStorage)：**
   - 建議於 `store.js` 或專用 `settings.js` 儲存學生之閱讀偏好：
     ```json
     {
       "fontSize": "normal",   // "normal" | "large" | "xlarge"
       "zhuyin": false,        // boolean
       "speechAuto": false,    // boolean
       "speechSpeed": 1.0,     // 0.8 | 1.0 | 1.2
       "reverseAlert": true    // boolean (預設 true)
     }
     ```
   - 頁面載入時：
     - 若 `fontSize === 'large'`，在 `<html>` 加上 `class="font-size-large"`；若 `xlarge` 加上 `class="font-size-xlarge"`。
     - 若 `zhuyin === true`，在 `<body>` 加上 `class="mode-zhuyin"`。
     - 若 `reverseAlert === false`，隱藏反向題橫幅並取消反向字底線。
3. **語音朗讀 Web Speech API 串接：**
   - 使用瀏覽器原生 `window.speechSynthesis`。
   - 語速對應：慢速 `rate = 0.8`、正常 `rate = 1.0`、快速 `rate = 1.2`；語言設為 `'zh-TW'`。
   - 若 `speechAuto === true`，進入新題目時自動朗讀題目與選項；單題朗讀按鈕 `.btn-speak-question`（🔊 朗讀本題）點擊時手動播放本題。
4. **題目反向題偵測：** 題目若帶有標籤 `反向題` 或題目文字含「不正確」、「何者錯誤」，且設定中 `reverseAlert !== false`，請套用：
   - `<div class="alert-reverse">...</div>`
   - 題目文字關鍵字包裹 `<mark class="highlight-reverse">不正確</mark>`
5. **無題幹圖片題處理：** 題目若 `question` 為空字串且帶有圖片，請於題幹位置套用 `<div class="question-stem-prompt"><span>👉</span> 請看圖，選出正確的答案。</div>`。
6. **圖片來源：** 題庫中的交通標誌與情境圖，請引用 `media/images/[題目編號].png` 或 `.jpg`，套用 `.question-image-frame` 樣式。
7. **階段 1 練習回饋限制：** 答題回饋僅顯示對錯與官方正確答案（如 `.option-card.is-correct`），**不顯示解析與口訣**（待階段 3 由 Jim 審核概念卡內容後再加入）。
8. **圖表呈現：** 結算頁中的雷達圖與長條圖，工程端約定使用 **Chart.js**，可直接掛載於 `.chart-wrapper` 的 `<canvas>` 中。
